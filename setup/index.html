Setup Guide

About a minute. App Commander walks you through the same steps on first launch.

Why a shortcut? iOS doesn't let one app open another by name. Apple's Shortcuts app can, so App Commander hands each launch to a small shortcut you add once. Apps that support direct links open without it.

Before you start

You need Apple's Shortcuts app. It comes with iOS, but it can be deleted; if it's missing, get it free from the App Store. App Commander tells you if it isn't installed.

1. Add the launch shortcut

  1. In App Commander, open → Shortcut Setup (or follow the first-launch steps) and tap Add Launch Shortcut.
  2. Shortcuts opens and shows App Commander Launcher. Tap Add Shortcut.
Screenshot: the “Add Shortcut” screen in Shortcuts

2. Turn on its automation

Shortcuts adds automations switched off, so this one step is yours:

  1. In Shortcuts, go to Automation.
  2. Switch on When App Commander is opened or closed.
  3. Go back to App Commander. In Shortcut Setup, the status turns green: Automation connected.
Screenshot: the Automation list in Shortcuts

3. The first launch

The first time App Commander opens an app this way, Shortcuts may ask: “Allow ‘App Commander Launcher’ to output 1 app?” Tap Always Allow so it doesn't ask again.

Optional: come back to App Commander

If you'd like App Commander to reopen when you leave an app by going to the Home Screen:

  1. In → Shortcut Setup, tap Add Return Shortcut, then Add Shortcut.
  2. In Shortcuts, go to Automation and tap When Settings is closed. Choose the apps you open from App Commander instead of Settings.
  3. Don't add App Commander or Shortcuts themselves.
  4. Back in Automation, switch it on.

Switching straight to another app (for example, swiping along the bottom of the screen) doesn't trigger it; only going to the Home Screen does.

Troubleshooting

Status stays “Not detected yet”

In Shortcuts, go to Automation and check that When App Commander is opened or closed is switched on. Then switch away from App Commander and back. Each device needs its own setup: automations don't turn on by themselves when shortcuts sync through iCloud.

“Couldn't find the shortcut”

If you renamed the shortcut, or Shortcuts added a number because you already had one (“App Commander Launcher 1”), enter its exact name in → Shortcut Setup → Shortcut name.

“Open App failed because no app was specified”

The app you tapped isn't installed on this device. Remove it from the page, or install it.
